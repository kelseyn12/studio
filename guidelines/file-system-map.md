# File system map

- `app/` routes: Today, pipeline, plan, calendar, campaigns, cards, Cuts, library, repurposer, transcriber, dms, analytics, connections, team, sign-in/sign-up, privacy and terms (public, no login)
- `app/api/` auth, files, assets, Outstand connect/sync, analytics sync, plan move, AI hook, transcribe, repurpose generate
- `guidelines/editor-guide.md` — the hand-out for the editor: sign in, Cuts folders, naming finished files, dropping them back.
- `components/` shell, nav, pills, action card, studio map, today board, plan board, hook rewrite, refresh stats, capcut link, batch settings, music volume (song under the voice), batch outputs, output tune, text style pick, batch targets, clip tile, slot block, hook logos, hook stage, use-keep-clear (headline clear of logos), hook list, list overlay, word chips, logo scale bar, spoken fix, align guides, cut track, cover pick, live looks, look account picks, editor need, packet files, calendar board, day slot, waiting videos (per-mix look pills + accounts on Live), editor batch (Cuts folder per Multiply batch: words, needs, Download all, drop by mix number), cuts bucket (loose videos on Cuts), post chip, card brief/footage/editor/live, paid button, failed posts, deal edit, deal bonuses (view bonus rows), storage meter, library deals/file, select videos, delete video, account deal (tap a deal on Accounts and it saves), schedule button (Scheduling… while a post goes out), day picks (grey out a mix already chosen on another day), cancel schedule (take a video off the calendar), new videos form (how many, then one title each), finished drop (IG · FB, TT · YT, or Both)
- `fonts/` TikTok Sans Bold (OFL), Inter Tight SemiBold (OFL stand-in for Instagram Sans), and Noto Emoji (OFL) for emoji marks and headline emoji advances
- `lib/` prisma, pipeline, new-videos (one title per new video), deals, deal-bonuses (flat month, view bonuses, one price per video), next-action, session, Clerk, R2, storage, library-groups, cut-ready (finished drop → To approve), editor-batches (words sheet, needed looks, file → mix match), waiting-folders, drop-cards, cut / cut-math (drop ranges + speed), hook-logos, emoji-image (color emoji art for marks), hook-emoji (headline emoji runs, spots, measured wrap), emoji-overlay (emoji PNG overlay stages), list-layout (native TT/IG metrics + shared list rows), hook-fonts / hook-font-files, Outstand, analytics, youtube-public (Studio view count), capcut (editor project link), formats, rewrite, whisper, script, pull-media, manychat, ffmpeg, trim (cuts + dead air), variations, combinations, same-take (body and CTA are the same recording), output-recipe (song start + quiet music under the voice), editor-packet, queries, publish, publish-sync (queued posts → published or failed per app; card → Posted; one retry), publish-sweep, ship-media (IG-safe remux + YouTube 1280×720 thumb), post-cover (cover frame → Outstand per-network fields + TikTok DIRECT_POST), media-url, render-batch, captions / captions-math / caption-ass (CapCut-style spoken), batch-polish, ingest, text-style, ass (libass hook text), targets, keep, sweep
- `prisma/schema.prisma` studio data model (`CutBy`, `User.clerkId`)
- `data/` local SQLite (CLI + fallback only — runtime uses Turso when TURSO_DATABASE_URL is set) and local upload fallback
- `Dockerfile` + `fly.toml` public host (sleeps when idle). App: https://system-studio.fly.dev
- `guidelines/` conventions, map, glossary, todo
- `README.md` stack, local setup, route overview, deploy notes
